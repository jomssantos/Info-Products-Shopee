# Info-Products-Shopee
Código que usa a api de afiliado shopee para extrair informações de produtos através do link.

Para usar a api oficial é nescessário se tornar afiliado se cadastrando no Programa de Afiliados Shopee. Em seguida, após se tornar afiliado, é preciso solicitar o acesso à api. Para fazer isso, basta ir na página principal e ir na sessão Abrir API e clicar em solicitar, passando por todas as etapas nescessárias.

Após ter acesso a api, na página da api estarão as informações APP_ID e Senha, basta colocar no codigo o APP_ID na variável <appid> e a Senha na variável <senha>.

Dessa forma basta colocar o link do produto desejado e o código funcionará.
